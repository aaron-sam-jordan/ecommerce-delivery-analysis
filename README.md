# E-Commerce Delivery Analysis (SQL Server)

Analysis of late deliveries in the Olist Brazilian e-commerce dataset (Kaggle).

**Tools:** SQL Server, SSMS (Power BI dashboard coming)

**Dataset:** Brazilian E-Commerce Public Dataset by Olist (Kaggle), 9 tables, about 100k orders.

## Questions answered
1. What share of delivered orders arrive late?
2. Which customer states have the highest late rate?
3. Which seller states ship the most late orders?
4. Does the late rate change by month?
